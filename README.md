# smart-expense-tracker
Smart Expense Tracker Web Application built using HTML, JavaScript, Chart.js and Tailwind CSS with localStorage support.
A modern web-based expense tracking application that helps users manage and analyze their daily expenses.

## 🚀 Features

- Add, Edit and Delete Expenses
- Monthly Total Calculation
- Highest Expense Detection
- Top Spending Category Identification
- Monthly Savings Recommendation
- Line Chart for Daily Expense Trends
- Pie Chart for Category Distribution
- Smart Insights and Budget Suggestions
- Data stored using Browser localStorage

## 🛠 Technologies Used

- HTML5
- CSS (Tailwind CSS)
- JavaScript (ES6)
- Chart.js
- Bootstrap Icons
- Google Fonts

## 📊 Functional Modules

1. Dashboard Summary
2. Add Expense Form
3. Expense List Table
4. Monthly Trend Line Chart
5. Category Distribution Pie Chart
6. Smart AI Insights Section

## 💾 Data Storage

All expense data is stored in browser localStorage.  
No backend or database is required.

## 📌 How to Run

1. Download the project
2. Open `Expenses Tracker.html` in your browser
3. Start adding expenses
